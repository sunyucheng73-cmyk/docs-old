## Overview

This tutorial builds a schematic-only ESP32 module development circuit similar
to the common Hardware Academy style ESP32 board: a pre-certified ESP32 module,
a 3.3 V regulator, reset and boot controls, USB-UART programming, decoupling,
and a small expansion header.

Using an ESP32 module instead of the bare ESP32 chip keeps the example practical
for first boards. The RF matching network, flash, crystal, and antenna are
already handled inside the module, so the schematic focuses on the parts a
custom carrier board still needs.

## Parts

- U1: ESP32-S3-WROOM-1-N8R2 module, or another JLCPCB-available ESP32-WROOM
  module variant with the same power, EN, BOOT, TXD, and RXD signals
- U2: 3.3 V regulator, such as AP2112K-3.3 or AMS1117-3.3
- U3: USB-UART bridge, such as CP2102N, CH340C, or CH343P
- J1: USB-C receptacle used for 5 V power and USB data
- SW1: Reset pushbutton
- SW2: Boot pushbutton
- C1-C6: input, output, and local decoupling capacitors
- R1-R6: pullups, USB-C CC resistors, and UART series resistors
- J2: expansion header for power, UART, I2C, and spare GPIO

:::tip
Choose module and USB-UART variants that are in stock at your assembler before
starting the PCB. The schematic below keeps the signal names generic so the
parts can be swapped without changing the tutorial flow.
:::

## Create the Circuit

Create a file named `lib/Esp32ModuleDevBoard.tsx` and start with the module,
regulator, USB connector, USB-UART bridge, switches, and header.

```tsx title="lib/Esp32ModuleDevBoard.tsx"
export const Esp32ModuleDevBoard = () => (

      schX={2}
      schY={0}
      footprint="jlcpcb:C2913200"
      schWidth={3.8}
      schHeight={5.6}
      pinLabels={{
        pin1: "GND",
```

## Add Power

USB-C provides 5 V on `VBUS`. The regulator turns that into the `3V3` rail used
by the ESP32 module, USB-UART bridge, and expansion header.

```tsx title="lib/Esp32ModuleDevBoard.tsx"
// Add inside <board>
<capacitor name="C1" capacitance="10uF" footprint="0603" schX={-6.5} schY={4.2} />
<capacitor name="C2" capacitance="100nF" footprint="0603" schX={-5.4} schY={4.2} />
<capacitor name="C3" capacitance="10uF" footprint="0603" schX={-2.7} schY={4.2} />
<capacitor name="C4" capacitance="100nF" footprint="0603" schX={-1.6} schY={4.2} />
```

## Add Reset and Boot

The ESP32 module needs `EN` pulled high for normal operation. Holding `GPIO0`
low while resetting enters the serial bootloader.

```tsx title="lib/Esp32ModuleDevBoard.tsx"
// Add inside <board>
<resistor name="R1" resistance="10k" footprint="0603" schX={-0.2} schY={4.6} />
<resistor name="R2" resistance="10k" footprint="0603" schX={-0.2} schY={-4.4} />
<capacitor name="C6" capacitance="100nF" footprint="0603" schX={1.1} schY={4.6} />

<trace from=".R1 > .pin1" to="net.3V3" />
<trace from=".R1 > .pin2" to="net.EN" />
<trace from=".SW1 > .pin1" to="net.EN" />
<trace from=".SW1 > .pin2" to="net.GND" />
<trace from=".C6 > .pin1" to="net.EN" />
<trace from=".C6 > .pin2" to="net.GND" />
<trace from=".U1 > .pin3" to="net.EN" />

<trace from=".R2 > .pin1" to="net.3V3" />
<trace from=".R2 > .pin2" to="net.BOOT" />
<trace from=".SW2 > .pin1" to="net.BOOT" />
<trace from=".SW2 > .pin2" to="net.GND" />
<trace from=".U1 > .pin4" to="net.BOOT" />
```

## Add USB-UART Programming

The USB connector feeds the USB-UART bridge. The bridge TX connects to ESP32 RX,
and bridge RX connects to ESP32 TX. Small series resistors make the UART lines
easy to isolate while debugging.

```tsx title="lib/Esp32ModuleDevBoard.tsx"
// Add inside <board>
<resistor name="R3" resistance="5.1k" footprint="0603" schX={-7.6} schY={-0.3} />
<resistor name="R4" resistance="5.1k" footprint="0603" schX={-7.6} schY={-1.2} />
<resistor name="R5" resistance="100" footprint="0603" schX={-1.3} schY={-1.8} />
<resistor name="R6" resistance="100" footprint="0603" schX={-1.3} schY={-2.7} />

<trace from=".J1 > .pin4" to=".R3 > .pin1" />
<trace from=".J1 > .pin5" to=".R4 > .pin1" />
<trace from=".R3 > .pin2" to="net.GND" />
<trace from=".R4 > .pin2" to="net.GND" />

<trace from=".J1 > .pin2" to=".U3 > .pin2" />
<trace from=".J1 > .pin3" to=".U3 > .pin3" />
<trace from=".U3 > .pin1" to="net.VBUS" />
<trace from=".U3 > .pin8" to="net.GND" />

<trace from=".U3 > .pin4" to=".R5 > .pin1" />
<trace from=".R5 > .pin2" to="net.ESP_RXD" />
<trace from=".U1 > .pin6" to="net.ESP_RXD" />
<trace from=".J2 > .pin4" to="net.ESP_RXD" />

<trace from=".U3 > .pin5" to=".R6 > .pin1" />
<trace from=".R6 > .pin2" to="net.ESP_TXD" />
<trace from=".U1 > .pin5" to="net.ESP_TXD" />
<trace from=".J2 > .pin3" to="net.ESP_TXD" />
```

## Add Expansion Signals

Expose a few module pins on a header so the board can be reused for sensors,
I2C devices, or quick bring-up wiring.


## Complete Example

Putting the sections together gives a compact schematic-only ESP32 module
development board. From here, you can add LEDs, sensors, or a battery charger
before laying out the PCB.

```tsx title="lib/Esp32ModuleDevBoard.tsx"
export const Esp32ModuleDevBoard = () => (
  <board width="55mm" height="35mm">
    {/* Paste the component definitions from Create the Circuit here. */}
    {/* Paste the power, reset, boot, USB-UART, and header traces here. */}
  </board>
)
```

## Schematic Checklist

Before moving to PCB layout, check the schematic against the ESP32 module
hardware guidelines:

1. The module has a stable 3.3 V rail with local 100 nF decoupling close to the
   module supply pins.
2. `EN` has a 10 k pullup and a reset button to ground.
3. `GPIO0/BOOT` has a 10 k pullup and a boot button to ground.
4. USB-C `CC1` and `CC2` each have 5.1 k pulldowns for a device-side USB-C port.
5. USB-UART TX goes to ESP32 RX, and USB-UART RX goes to ESP32 TX.
6. The antenna end of the ESP32 module will sit at the board edge with copper
   keepout under and in front of the antenna.

## Next Steps

- Swap the ESP32 module or USB-UART bridge for parts that are available from
  your assembler.
- Add auto-reset transistors using the USB-UART `DTR` and `RTS` pins.
- Add power and status LEDs.
- Add a LiPo charger or external 5 V input if the board will not always use USB.
- Move from schematic-only to PCB layout and add the required antenna keepout.
